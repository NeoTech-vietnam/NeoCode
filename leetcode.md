# What Is LeetCode?

LeetCode is an online platform for practicing programming problems, especially data structures and algorithms (DSA). You can read a problem's requirements and constraints, write code in an online editor, run it against examples, and submit it to be checked against additional test cases. An **Accepted (AC)** result means the submission passed the platform's tests; it is useful feedback, but does not by itself show that you can solve or explain the problem independently.

## Using LeetCode with This Repository

This repository follows a C-first roadmap for firmware interview practice. Use the topic order and starter problems in the [roadmap](README.md), then:

1. Read the problem and constraints, and work through small examples yourself.
2. Write your C solution in that problem's `solution.c`; use `test.c` and `tools/build_test.py` for local checks.
3. Paste the solution into LeetCode and submit it yourself. LeetCode submissions are separate from this repository's local tests.
4. Review any failures, then record the result and whether you used help in `progress.md`.
5. Re-solve the problem later without looking at the answer. Once the C fundamentals are solid, compare with a C++ version as described in the roadmap.

Use LeetCode to get practice and feedback. Focus on understanding why a solution works, its time and space costs, and whether you can reproduce and explain it on your own.

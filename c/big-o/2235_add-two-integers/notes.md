## Task

Given two integers `num1` and `num2`, return their sum. Each input is between
-100 and 100 inclusive. Implement `int sum(int num1, int num2)` in `solution.c`.

Examples: `(12, 5)` gives `17`; `(-10, 4)` gives `-6`.
